# Обновление платформы — 6 марта 2026

## 📚 База знаний (Wiki KB)

### Поиск по базе знаний
- Добавлена страница `/kb/search/` — полнотекстовый поиск по заголовкам и содержимому статей
- Поддержка фильтрации по диапазону дат последнего изменения («Изменено с» / «Изменено по»)
- Строка быстрого поиска добавлена в боковую панель навигации — клик → страница результатов
- Каждый результат показывает заголовок, превью содержимого и дату изменения

### Перенос статей в иерархии
- Кнопка **«Перенести»** на странице каждой статьи
- Визуальный выбор нового места в дереве: кликаешь на нужный раздел или «Корень базы знаний»

### Создание статьи из записи встречи
- Кнопка **«📄 Создать вики»** на странице каждой транскрибированной записи
- Выбор места в иерархии базы знаний
- После выбора — автоматическая генерация содержимого через LLM по тексту транскрипции
- Сгенерированная статья структурирована: резюме встречи, ключевые решения, задачи, факты и цифры

### Публичные страницы
- Кнопка **«📚 Работать с вики»** внизу каждой публичной страницы — ведёт на главную (авторизация)

## ⚙️ Настройки LLM API в админке

Раздел **«Настройки LLM API»** в `/admin/` — теперь можно управлять без перезапуска сервера:

| Поле | Описание |
|---|---|
| **URL API** | Адрес эндпоинта LLM |
| **Authorization** | Значение заголовка авторизации |
| **Referer** | Значение заголовка Referer |
| **Шаблон запроса (JSON)** | Редактируемая структура тела запроса |
| **Ключ ответа** | Ключ для извлечения текста из JSON-ответа |

**Шаблон запроса** поддерживает плейсхолдеры:
- `{prompt}` — текст запроса к LLM
- `{session_id}` — идентификатор сессии
- `{log_id}` — идентификатор лога

Кнопка **«⚡ Проверить соединение с API»** — тестовый запрос прямо со страницы настроек без перезагрузки.

## 🐛 Исправления

### Бургер-меню на мобильных устройствах
- **Проблема:** меню открывалось, но ни одна кнопка не кликалась
- **Причина:** `z-index` оверлея (1000) был выше стекинг-контекста хедера (100), поэтому оверлей перехватывал все клики
- **Решение:** при открытом меню хедер поднимается выше оверлея (`z-index: 1050`)

### Логотип в светлой теме
- **Проблема:** текст «BusinessPad» в SVG-логотипе (`fill="white"`) не читался на белом фоне
- **Решение:** в светлой теме логотип размещается на тёмно-синем фоне (`#1d3e84`), соответствующем фирменному цвету

### Реактивные фильтры по имени файла (главная страница)
- Добавлены кнопки **CPQ** и **Dev** в строку быстрых фильтров
- Работают мгновенно (без перезагрузки), совместно с фильтром по тегу
- Повторный клик по активной кнопке сбрасывает фильтр
