О приложении

«Записи встреч» — сервис для хранения аудио- и видеозаписей встреч с автоматической транскрипцией, поиском по тексту и по смыслу, а также распознаванием текста в документах (OCR).

AI-инструменты (текущие)

Сейчас в приложении: транскрибация (faster-whisper, качество и язык), AI-название и саммари (внешний LLM), эмбеддинги и семантический поиск (sentence-transformers + pgvector), полнотекстовый поиск (PostgreSQL), OCR (внешний API / olmOCR).

Дополнительные AI-инструменты (идеи)

Расширение возможностей за счёт новых ИИ-функций:

  • Извлечение action items — из транскрипции автоматически вытаскивать задачи, дедлайны и ответственных (NER + LLM или только LLM).
  • Структурированное саммари — разбивка на блоки: повестка, решения, риски, следующие шаги, открытые вопросы.
  • Дираизация спикеров — «кто что сказал» (pyannote или аналог), подписи к репликам в транскрипции.
  • Ключевые фразы и теги — автоматические ключевые слова или теги по содержанию (эмбеддинги или LLM).
  • Перевод транскрипции — перевод готового текста на другой язык (внешний переводчик или LLM).
  • Вопрос-ответ по записям (RAG) — один запрос по одной записи или по всем: поиск релевантных фрагментов + ответ на основе контекста (LLM).
  • Определение тональности — оценка тона по сегментам или по всей встрече (для ретро и обратной связи).
  • Черновик письма после встречи — генерация follow-up письма или краткого отчёта по саммари и action items.
  • Поиск по спикеру — фильтр «кто сказал» при наличии диараизации.
  • Похожие встречи — поиск записей с близкой тематикой (по эмбеддингам) или дубликатов.
  • Таймлайн тем — какие темы поднимались в каких встречах за период.
  • Сравнение двух встреч — что изменилось, новые решения, повторяющиеся пункты.
  • Редоктирование и PII — маскирование персональных данных и чувствительных фрагментов перед сохранением или экспортом.

Мультиагентные сценарии

Варианты оркестрации нескольких «агентов» (сервисов или шагов ИИ):

  • Пайплайн после загрузки — оркестратор по очереди: транскрибация → саммари → извлечение action items → автотеги → индексация эмбеддингов; каждый шаг — отдельный агент/воркер.
  • Исследовательский агент — пользователь задаёт вопрос; планировщик разбивает задачу; один агент ищет по транскрипциям, другой — по OCR-документам, третий собирает и формулирует ответ (RAG поверх всех источников).
  • Модерация перед публикацией — агент 1: транскрипция; агент 2: проверка на PII и чувствительные данные, редоктирование; агент 3: финальное сохранение и индексация.
  • Контроль качества транскрипции — первый агент даёт черновик транскрипции, второй «рецензирует» и предлагает правки, третий принимает решение и сохраняет итоговый текст.
  • Подготовка и закрытие встречи — до встречи: агент собирает саммари прошлых встреч по теме, предлагает повестку; после: саммари, action items, распределение по людям, черновик отчёта или письма.
  • Мультиисточниковый поиск — маршрутизатор по типу запроса отправляет в агент поиска по транскрипциям, по OCR или в обоих; агент-комбайнер объединяет результаты и ранжирует.
  • Тренды и отчёты — агент по расписанию анализирует новые записи: тональность, частые темы, рост/снижение упоминаний ключевых слов; второй агент формирует еженедельный или ежемесячный отчёт.

Такие сценарии можно реализовывать по шагам: сначала отдельные инструменты, затем оркестратор (очереди, Celery или вызовы между сервисами).

Записи

Записи хранятся в S3. Новые файлы (MP3) подхватываются поллером: после стабилизации размера файла запись попадает в очередь транскрибации. На главной странице можно смотреть записи по дате, фильтровать по тегу, искать по тексту транскрипции или по смыслу (семантический поиск при наличии pgvector).

  • Статусы: ожидание (копируется), готов к транскрибации, транскрибируется, готово, ошибка.
  • Теги: аналитика, бекенд, инфра, дейли, маркетинг, фронт.
  • Для каждой записи доступны транскрипция, AI-название и саммари (если включены), скачивание MP3 и текста, комментарии.

Загрузки и OCR

В разделе «Загрузки видео» можно загрузить аудио или видео — файл конвертируется в MP3 (если установлен ffmpeg) и ставится в очередь транскрибации. В разделе «OCR» можно загрузить PDF или изображение — документ отправляется во внешний API распознавания и результат отображается в виде Markdown.

Логи и очереди

В «Логах» отображается история опроса S3 (найдено файлов, стабильных, транскрибировано). Транскрибация и индексация эмбеддингов выполняются воркерами по очередям; при необходимости можно запустить один цикл опроса вручную с главной страницы.
